🌐 Redes de Computadores

Entenda como dispositivos se conectam e trocam informações

📌 Conceito de Rede

Uma rede de computadores é formada por dispositivos interligados com o objetivo de compartilhar dados e recursos, como arquivos, impressoras e acesso à internet.

Principais elementos:

  • Dispositivos: computadores, celulares e servidores
  • Meios: cabos ou conexões sem fio
  • Equipamentos: roteadores e switches

📊 Tipos de Redes

Sigla Nome Descrição
PAN Personal Area Network Conexões pessoais de curto alcance
LAN Local Area Network Rede local (casa ou empresa)
MAN Metropolitan Area Network Rede que cobre uma cidade
WAN Wide Area Network Rede de longa distância (Internet)

🔗 Topologias

Define como os dispositivos estão conectados:

  • Estrela: todos conectados a um ponto central
  • Malha: vários caminhos entre os dispositivos

📚 Modelo OSI

Divide a comunicação em 7 níveis:

  1. Física
  2. Enlace
  3. Rede
  4. Transporte
  5. Sessão
  6. Apresentação
  7. Aplicação

🌍 Protocolos

  • IP: identifica dispositivos
  • TCP: garante entrega correta
  • DNS: traduz nomes para IP
  • HTTP/HTTPS: carregamento de sites
